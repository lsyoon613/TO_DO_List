# 오늘 할 일 · TrayTodo

Windows 11 시계 옆 트레이에서 열 수 있는 가벼운 할 일 앱입니다. 작업표시줄의 밝게/어둡게 설정에 맞춰 표시됩니다.

## 바로 다운로드

**[TrayTodo.exe 다운로드](https://github.com/lsyoon613/TO_DO_List/raw/refs/heads/main/downloads/TrayTodo.exe)**

Windows 11에서 다운로드한 파일을 원하는 폴더에 저장하고 실행하세요. 별도 설치 과정은 없습니다. 실행 파일 하나만 전달해도 사용할 수 있으며 개인 할 일 데이터는 포함되지 않습니다.

## 기능

- 할 일 작성·수정과 마감일 지정
- 입력 칸에서 **Enter**로 추가·저장 (선택 목록이 열려 있으면 선택 확정)
- **시작 전 / 작업 중** 진행 상태 선택
- 완료 체크 시 완료 탭으로 이동, 체크 해제로 복원
- 과목명을 굵게 표시하고 과목별 폴더처럼 모아보기
- 마감일이 빠른 순으로 정렬, 마감일 없는 작업은 마지막에 표시
- 마감 이틀 전부터 미완료 작업을 하루 한 번 알림
- 시작 전인 마감 임박 작업에 경고 알림과 주황색 경고 문구 표시
- 로컬 자동 저장과 직전 저장본 백업

## 사용법

1. `TrayTodo.exe`를 실행합니다.
2. 트레이의 파란 체크 아이콘 또는 **Ctrl+Alt+T**로 패널을 엽니다. 아이콘이 안 보이면 작업표시줄의 숨겨진 아이콘 목록에서 찾으세요.
3. 내용을 입력하고 필요하면 과목·진행 상태·마감일을 지정한 뒤 **Enter** 또는 **추가**를 누릅니다. 새 과목은 과목 입력 칸에 직접 작성합니다.
4. 작업 오른쪽 **···**로 내용을 수정합니다. 완료 체크는 **완료** 탭으로 작업을 옮깁니다.
5. 패널의 X 또는 Esc는 숨기기입니다. 완전히 종료하려면 트레이 아이콘을 우클릭하고 **종료**를 선택합니다.

트레이 우클릭 메뉴에서 **Windows 시작 시 실행**과 **알림 테스트**를 사용할 수 있습니다. 자동 시작을 켠 뒤 실행 파일을 다른 폴더로 옮겼다면 새 위치에서 자동 시작을 껐다 켜주세요.

## 알림과 데이터

알림은 앱이 실행 중일 때 약 1분 간격으로 확인합니다. PC가 꺼져 있거나 앱을 종료한 동안에는 알림을 보내지 않으며, 다시 실행하면 남은 작업을 확인합니다. 마감이 지난 미완료 작업도 포함합니다. 같은 날 같은 작업·마감일에 대해서는 알림을 반복하지 않으며 마감일을 변경하면 다시 알릴 수 있습니다. Windows 알림 차단이나 방해 금지 설정에 따라 배너가 표시되지 않을 수 있습니다.

데이터는 각 사용자의 `%LOCALAPPDATA%\TrayTodo\tasks.json`에 저장되며 직전 저장본은 `tasks.json.bak`입니다. 온라인 전송이나 계정 연결은 없습니다. 다른 PC로 데이터를 옮기려면 양쪽 앱을 종료한 후 해당 파일을 같은 위치에 복사하세요.

기본 Windows 알림·달력 패널 내부를 변경하는 앱은 아니며, 비슷한 위치에서 사용하는 독립 패널입니다. 과목 폴더는 앱 안의 분류이며 실제 파일 폴더를 만들지는 않습니다.

## 소스에서 빌드

Windows의 .NET Framework 4.x와 WPF를 사용합니다. Windows 11의 기본 .NET Framework 컴파일러로 빌드하므로 별도 NuGet 패키지나 .NET SDK는 필요하지 않습니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\test.ps1
```

빌드 결과는 저장소 루트의 `TrayTodo.exe`입니다. 배포 파일을 갱신할 때 검증한 결과를 `downloads/TrayTodo.exe`로 복사합니다. GitHub Actions에서도 빌드와 저장·복원·알림 조건 테스트를 실행하고 실행 파일을 아티팩트로 제공합니다.

| 파일 | 용도 |
| --- | --- |
| `TrayTodo.cs` | 앱 동작, 로컬 저장, 트레이, 알림 |
| `Main.xaml` | 화면과 컨트롤 디자인 |
| `build.ps1` | Windows 빌드 |
| `test.ps1` | 임시 데이터로 자동 검증 |
| `downloads/TrayTodo.exe` | 바로 실행할 수 있는 배포 파일 |

테스트는 임시 데이터를 사용하며 실제 할 일 파일을 변경하지 않습니다. 개인 데이터와 로컬 테스트 결과는 `.gitignore`로 제외합니다.
